# IPL Performance Analysis Dashboard (2008–2017)

> An interactive Power BI analytics project exploring IPL match, team, player, season, toss, and venue-level performance across ten seasons of the Indian Premier League.

## 📊 Project Overview

This project was developed as part of my **Business Analytics Internship at Labmentix** to transform historical IPL match and delivery data into an interactive analytical dashboard.

The dashboard explores how teams and players performed across seasons, identifies important performance patterns, and examines the impact of toss decisions, venues, and individual contributions on match outcomes.

The project combines **data preparation, analysis, visualization, and storytelling** into a multi-page Power BI dashboard designed for both detailed exploration and executive-level insights.

## 📌 Dashboard Pages

### 1. IPL Overview
A high-level view of the tournament covering:
- Total matches and seasons analyzed
- Season-wise match trends
- Toss decision distribution
- Match result distribution
- Top host cities
- Key tournament-level insights

### 2. Team Performance Analysis
An analysis of team success and toss-related patterns, including:
- Top winning teams
- Team-wise performance
- Toss-winning teams
- Toss decision trends
- Match distribution across seasons
- Host venue patterns

### 3. Player Performance Analysis
An exploration of individual player contributions across batting, bowling, and fielding:
- Top run scorers
- Top wicket takers
- Players with the most sixes
- Players with the most fours
- Player of the Match performance
- Top fielders based on catches and run-outs

### 4. Executive Dashboard
A consolidated view of major tournament, team, and player insights designed for quick decision-making and high-level analysis.

## 🔍 Key Insights

- **636 IPL matches** were analyzed across **10 seasons (2008–2017)**.
- **2013** recorded the highest number of matches in the analyzed period.
- Teams winning the toss chose to **field first more frequently (57.1%)** than bat first.
- Approximately **98.4% of matches ended with a normal result**.
- **Mumbai** hosted the highest number of IPL matches among the cities analyzed.
- **Mumbai Indians** emerged as the most successful team by match wins in the analyzed dataset.
- **Suresh Raina** was the highest run scorer among the displayed players.
- **Lasith Malinga** recorded the highest number of wickets among the analyzed bowlers.
- **Chris Gayle** recorded the highest number of sixes among the displayed players.
